# Выгрузка оставшегося каталога Split Home

Это добавочная разовая выгрузка для ручного импорта в VK, не синхронизация магазина.
Она не вызывает публикацию через API, не меняет БД сайта и не заменяет старый YML.

## Источник

`scripts/vk_catalog_snapshot.py` запускается внутри существующего Django-приложения.
Транзакция READ ONLY. Фильтр совпадает с публичным каталогом: `is_active`, включённая
категория, розничный `kind`. Цена — только `ric`, которую видит посетитель сайта,
с тем же округлением до рубля. Оптовые цены и секреты в снимок не входят.

Снимок включает наличие и ассортимент под заказ. Он хранится локально в
`artifacts/vk-market-20260831/`, исключённом из Git из-за объёма.

## Сборка

```powershell
$env:PYTHONPATH='src'
python -m content_factory.storefront.vk_catalog_export `
  --snapshot artifacts/vk-market-20260831/catalog-snapshot.json `
  --existing-feed 'C:\Users\TLT-1\Downloads\vk-market-import.yml' `
  --output artifacts/vk-market-20260831/remaining `
  --exclude-id 'breeze:НС-1693081'
```

- Исключаются 44 ID из прежнего файла и известная карточка XIGMA SKY21.
- Исключается та же модель другого поставщика: бренд + точный артикул;
  числа, мощности и пунктуация артикула сохраняются. Не объединяются целые серии.
- Для настоящего дубля предпочтение — наличие в Крыму, затем другие склады,
  затем меньшая публичная цена. Все исключения отражаются в отчёте.
- Пропускаются товары без положительной розничной цены, без фото, не в рублях.
- Изображения проверяются GET-чтением первых 64 КиБ: JPEG/PNG, обе стороны
  не меньше 400 px, отношение не больше 20. Это проверка заголовка, а НЕ полное
  декодирование изображения. Проверяются до четырёх фотографий товара.
- Сетевые таймауты повторяются один раз. Отрицательные результаты остаются в отчёте.
- Названия/описания очищаются от HTML и недопустимых XML-символов. Характеристики
  помещаются в текст, а не в `param`, чтобы не превышать ограничение свойств VK.
- Очищается и HTML, который поставщик уже экранировал как `&lt;p&gt;`.
- Прежние ID категорий 1–4 сохраняются для масла/водонагревателей/пола/регуляторов;
  для остальных категорий используется отдельный диапазон 1000+. Явно названные
  комплектующие, оконные кондиционеры и вентустановки ошибочного исходного
  раздела «Бытовые сплит-системы» в выгрузке получают корректную подборку.
- Используются постоянные `source:nc_code`, ссылки на конкретный товар, а не главную.
- Группы делятся на части строго меньше 7 800 000 байт; это меньше 8 МБ в обоих
  распространённых определениях. Между файлами нет пересекающихся ID.
- Проверяется общий лимит магазина 15 000 с учётом известных прежних товаров.

## Проверка результата

`report.json` содержит полный учёт: выгружено + причины пропусков = снимок каталога.
`image-audit.json` — локальный кэш проверок, он не предназначен для загрузки в VK.
Для импорта используются только файлы `.yml`, перечисленные в отчёте.
Старый 44-товарный файл и отдельный retry бойлера в новую пачку повторно не входят.

Общий список магазина через `market.get` с текущим ключом сообщества недоступен
(ошибка 27). Поэтому нельзя гарантировать отсутствие новых ручных карточек,
которые владелец мог добавить помимо известных. Стабильный ID сам по себе не
доказывает, что повторная загрузка файла в интерфейсе VK никогда не создаст дубль.

Файлы — снимок цен и наличия на дату сборки. Перед следующим массовым импортом
их нужно обновить, а уже импортированные ID — исключить. Не включать режим
полной замены каталога; дождаться завершения каждой части перед следующей.

## Результат 31.08.2026

- Каталог: 14 428 позиций. Добавочная выгрузка: 13 618 товаров, 16 файлов.
- 374 без публичной цены, 288 без фото, 94 без подходящего доступного изображения.
- 45 известных прежних позиций исключены; 9 точных дублей моделей исключены.
- Максимальный файл: 7 795 189 байт, менее 8 000 000.
- Публичный каталог файлов: `https://splithome.ru/static/vk-catalog-20260831-ready/`.
- Инструкция со всеми ссылками: `import-links.txt`; состав и размеры: `manifest.json`.
- Локальные подробные отчёты: `artifacts/vk-market-20260831/remaining/report.json`
  и `publication-verification.json` (результат полного GET и SHA-256 каждого файла).
- Полный контрольный GET выполнен с VPS по публичным HTTPS-адресам. Из соединения
  рабочего компьютера часть скачиваний прерывалась по таймауту, поэтому успешную
  внешнюю проверку всех файлов с компьютера утверждать нельзя; точка проверки
  явно записана в `vantage`. Сервисы сайта не перезапускались.
- Импорт в VK не запускался; опубликованы только файлы для ручного импорта.

Публикация выполняется `scripts/vk_catalog_publish.py` с проверкой списка файлов,
лимита, уникальности ID, обязательных полей, отсутствия HTML и контрольных сумм.
Новый каталог публикуется атомарным переименованием; старый не перезаписывается.
