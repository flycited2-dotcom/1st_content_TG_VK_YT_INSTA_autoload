# Омниканальная архитектура Content Factory

## Цель

Единый конвейер самостоятельно выбирает тему или товар, собирает проверяемые данные и медиа,
создаёт версии материала под каждую площадку, проводит строгую редакторскую проверку и только
после разрешения передаёт публикацию платформенному адаптеру.

## Конвейер агентов

1. **Планировщик** — выбирает цель, рубрику, товар и время выхода.
2. **Исследователь** — собирает факты, цены, наличие, характеристики и источники.
3. **Медиа-агент** — подбирает исходные фотографии или ставит задачу генератору изображения/видео.
4. **Редакторы площадок** — создают отдельные версии для Telegram, VK, Instagram и YouTube.
5. **Критик** — проверяет факты, цену, наличие, стиль, запрещённые темы и технические лимиты.
6. **Человек на ревью** — на полуавтоматическом этапе подтверждает, отклоняет или возвращает материал.
7. **Публикаторы** — работают через официальные API и сохраняют идентификатор опубликованного материала.
8. **Аналитик** — собирает показы, переходы, обращения и продажи и корректирует будущий контент-план.

## Этапы реализации

- [x] Базовый Telegram-конвейер: каталог → цена → карточка → правила → ревью → публикация.
- [x] Read-only подключение категории стабилизаторов с `climat-simf.ru`.
- [x] Закрытый пилот из трёх карточек стабилизаторов в Telegram-ревью (`pilots.stabilizers_review`).
- [x] VK Publisher: адаптация Telegram HTML → VK, загрузка фото и `wall.post`; первый запуск только `dry_run`.
- [x] Целевая стена подтверждена: бизнес-сообщество VK `club241020718`, личная страница исключена.
- [ ] Закрытый тест VK после добавления токена издателя с правами сообщества.
- [ ] Instagram Publisher через официальный Meta API и форматы пост/Reels/Stories.
- [ ] YouTube Publisher для Shorts и длинных видео.
- [ ] Единый контент-план и медиатека для всех площадок.
- [ ] Сбор аналитики, UTM-разметка и связь обращения с публикацией.
- [ ] Переход от обязательного ручного одобрения к автономности по уровням риска.

## Безопасность публикаций

- Секреты находятся только в `.env` или хранилище секретов и никогда не коммитятся.
- Новая площадка сначала работает в preview/dry-run, затем в закрытом пилоте.
- Политика и новостной контент запрещены на уровне планировщика и критика.
- Цена и наличие берутся из источника непосредственно перед созданием материала.
- До отдельного решения владельца новые кампании имеют `auto_tasks: []`.

## Git-процесс

Одна завершённая задача оформляется отдельным коммитом с тестами и отправляется в этот репозиторий.
Незаконченная работа, локальные состояния, токены, SSH-ключи и пользовательские черновики не коммитятся.
