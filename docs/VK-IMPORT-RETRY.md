# Повторный импорт отказавших товаров VK

Команда готовит отдельный YML по отчёту ошибок VK, не вызывает API и не запускает импорт.
Артикулы, цены, описания и порядок элементов товара сохраняются. В новый файл входят
только ID из отчёта. Апостроф, добавленный VK перед артикулом для Excel, снимается.
Пустой отчёт, отсутствующий ID, повторяющиеся ID в источнике и перезапись входных
файлов запрещены. Повторную загрузку всего каталога вместо одной ошибки не делать.

```powershell
$env:PYTHONPATH='src'
python -m content_factory.storefront.vk_import_retry `
  --source 'C:\path\vk-market-import.yml' `
  --errors 'C:\path\product_import_error_log.csv' `
  --output 'C:\path\vk-market-retry.yml' `
  --picture 'supplier:sku=https://example.com/static/vk-import-media/image.png'
```

Сначала проверить изображение обычным GET без авторизации, затем полное декодирование,
формат и размеры. Команда проверяет структуру YML, но сама не проверяет сетевые URL.
Перед повторным импортом убедиться, что отказавший товар действительно отсутствует
в сообществе: сохранение ID само по себе не доказывает дедупликацию на стороне VK.
Использовать добавление товаров, не режим полной замены/синхронизации каталога.

## Проверка 31.08.2026 — Royal Thermo Trend 80

- Исходный `vk-market-import.yml`: 44 предложения. В CSV ошибок одна позиция:
  `rusklimat:НС-1588136`, «Произошла проблема с загрузкой изображения».
- Nginx: 31.08.2026 15:09:26 МСК запрос VK-HUB к исходному PNG завершён HTTP 200,
  передано 1 827 988 байт. В серверном журнале ошибки для этого запроса не найдены.
- PNG: RGB, 1254 × 1254, без анимации; `Pillow.verify()` и полная загрузка проходят.
  Следовательно, точная внутренняя причина отказа VK не установлена; нельзя утверждать,
  что фото отсутствовало, было повреждено или имело неверный размер.
- Для повторной попытки опубликована побайтовая копия под ASCII-именем:
  `https://splithome.ru/static/vk-import-media/royal-thermo-trend-80-39d9df0db2764a28.png`.
  SHA-256: `39d9df0db2764a288abaa9182659719a27743c3f11910831a46ed1a72f87bb94`.
  Это новый URL для повторной обработки, а не доказанное исправление причины внутри VK.
- Проверочный GET: HTTP 200, полный размер, 0,66 с; SHA-256 совпадает.
- Подготовлен `vk-market-retry-royal-thermo-20260831.yml` в Downloads владельца:
  одно предложение с прежним ID и ценой 8505. Старый YML, отчёт и изображение сохранены.
- Новый импорт в VK не запускался. Итог VK требует проверки после ручного импорта.

Полный каталог в публичной выгрузке не заменён однотоварным файлом.
