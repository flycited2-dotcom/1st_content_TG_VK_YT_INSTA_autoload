# Обложки товаров VK Market

Первая фотография товара одна для мобильного и настольного интерфейса. VK может
центрально кадрировать её по-разному, поэтому базовый формат — квадрат `1:1`, а не
отдельная мобильная картинка.

Правила универсальной обложки:

- логотип, название, товар и короткие характеристики — только в центральных 75–80% ширины;
- внешние 10–12,5% слева и справа — фон без значимой информации;
- цена не вшивается в изображение и всегда берётся из актуального каталога;
- подробная инфографика загружается второй фотографией;
- геометрия товара повторяет исходное фото поставщика без перерисовки корпуса;
- перед тиражированием шаблон проверяется в мобильном списке товаров и на компьютере.

Файлы пилота:

- `xigma-sky-universal-square.png` — основной кандидат на первую фотографию;
- `xigma-sky-mobile-portrait-test.png` — тест вертикальной гипотезы, не использовать
  как стандарт без проверки настольного отображения.
- `shtil-is3000rt-universal-square.png` — стабилизатор Штиль ИнСтаб IS3000RT;
- `powerman-avs-2000s-universal-square.png` — стабилизатор POWERMAN AVS 2000S;
- `powerman-back-pro-1050-universal-square.png` — ИБП POWERMAN Back Pro 1050.

Тексты, розничные цены и ссылки для загрузки трёх новых позиций находятся в
`pilot-stabilizers-ups-2026-08-23.yaml`. Цена на изображениях намеренно отсутствует:
перед публикацией она повторно сверяется с карточкой сайта.
